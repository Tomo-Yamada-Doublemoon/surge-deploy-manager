# Surge Deploy Manager

Surge アカウントでログインし、デプロイ一覧の確認と選択削除ができるローカル管理ツールです。

UI は Next.js + shadcn/ui + Tailwind CSS です。

## ⚠️ 絶対にpublicへデプロイしないこと

このアプリは **Surgeのメール/パスワードを直接受け取り、削除まで実行します。** Vercel・Netlify・その他いかなる公開URLにもデプロイしないでください。公開した瞬間、そのURLにアクセスできる誰もがSurgeアカウントの資格情報を入力できる状態になり、アカウント乗っ取り・デプロイ全削除につながります。

**必ず`git clone`してローカル(`http://127.0.0.1:3847`)でのみ動かしてください。**

## 背景

AI-Driven Schoolで Surge にデプロイしながら図解をたくさん作ってきたなかで、「どんな図解があるか」を記録・整理したくなりました。ところが Surge 側には、デプロイを一覧で確認する機能がありません。そのため、ローカルで一覧を見て必要なものを整理できるツールを作ることにしました。

## なぜ Vercel 公開にしなかったか

Next.js なので Vercel に載せることは検討しました。ただしこのアプリは Surge のメールとパスワードを受け取り、削除まで行います。公開 URL にすると、他人のサイトへ資格情報を打つ形になり、信頼と誤操作の両方で向きません。自分専用の保護付きデプロイでも、パスワード受付の性質は変わりません。

共有するなら公開アプリではなく、このリポジトリを clone して各自のパソコンで動かす前提にしています。資格情報は自分のマシンから出ません。

## セットアップ

前提: Node.js 20 以上（`node -v` で確認）

```bash
git clone https://github.com/Tomo-Yamada-Doublemoon/surge-deploy-manager.git
cd surge-deploy-manager
npm install
npm run dev
```

`npm run dev` が起動したら、ブラウザで http://127.0.0.1:3847 を開きます。環境変数や追加設定は不要です。

## 使い方

1. Surge にログインしているメールアドレス / パスワードを入力してログインします（Surge公式APIに直接送信されるだけで、このアプリ側には保存されません）。
2. ログインするとデプロイ済みドメインの一覧がすぐ表示されます。タイトルや作成/更新日はバックグラウンドで順次取得されるので、少し待つと埋まっていきます（進捗表示・途中キャンセルあり）。
3. ドメインにフォーカスまたはカーソルを当てると、約0.4秒後に縮小プレビュー（iframe）が出ます。クリックすると通常どおり別タブでサイトが開きます。サイト側がiframe埋め込みを禁止している場合やsandbox制限でスクリプト前提のページは、プレビューが空／不完全になることがあります。
4. 不要なデプロイはチェックして削除できます。**削除は即座にSurge側から消え、復元できません。** 必ず自己責任で実行してください。
5. 使い終わったら、起動したターミナルで `Ctrl+C` を押して開発サーバーを止めます。ログイン情報はサーバープロセスのメモリ上にしか無いため、停止と同時に破棄されます。

### ポートが使用中の場合

3847番ポートが別プロセスに使われていると `npm run dev` が失敗します。`lsof -i :3847` で使用中のプロセスを確認し、不要なら終了してから再実行してください。

## 構成

| 場所 | 役割 |
|------|------|
| `app/` | 画面と API（ログイン・一覧・詳細取得・削除） |
| `components/` | UI。`ui/` は shadcn 部品 |
| `lib/` | Surge とのやり取りと一覧ロジック。テストは `lib/__tests__/` |
| `public/` | 静的ファイル |

スクリーンショット、図解の下書き、デプロイ履歴は `_local/` に置き、リポジトリには含めません。

## 注意

- **Surge から削除したデプロイは完全に消えます。** 復元はできません。削除の判断は必ず自己責任でお願いします。
- トークンはメモリ上のセッションにのみ保持します（`~/.netrc` は変更しません）
- `data.json` はレガシーのローカルキャッシュ用で、現行アプリでは使いません
